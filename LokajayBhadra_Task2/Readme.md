# Lokajay Bhadra - Task 2

## Laundry Wallah / Laundry Mart

This is a simple HTML webpage for a laundry service.

### Files
- `index.html` — webpage containing the welcome section, about paragraph, laundry image, services list, price list, booking form, and contact email.
- `laundry.jpg` — image used on the webpage.

### How to run
1. Keep `index.html` and `laundry.jpg` in the same folder.
2. Open `index.html` in a web browser.

Note: The booking form is an HTML demonstration. It does not send or store bookings.
